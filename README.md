# DataBV Earth 🌎

**Weather & Natural Events Monitor**

**DataBV Product | In Development**

## Overview

Inspired by my experience in the **NASA Space Apps Challenge 2026** ([View project](https://github.com/biavascobv/nasaspaceappschallenge_data)), DataBV Earth is a lightweight web application designed to make weather information and natural event data more accessible.

The application will connect to official weather APIs and NASA data sources, allowing users to explore weather conditions and recent natural events through a simple, responsive interface.

Designed for both mobile and desktop devices, the project focuses on accessibility, usability, and clear data visualization.

## Planned Features

- Weather information by location.
- Recent natural events using NASA's EONET data.
- Simple visualizations and event information.
- Basic safety guidance for different types of natural events.
- Responsive design for mobile and desktop devices.

## Data Sources

- **NASA EONET** — Natural event information.
- **Weather API** — To be defined.
